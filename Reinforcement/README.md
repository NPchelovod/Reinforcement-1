# ЕС BIM — исправленный кандидат v2

02.10.2026. Задача №2, исправления по замечанию пользователя к v1. Revit 2024, .NET Framework 4.8, C# 7.3, x64. Версия DLL 0.1.1.0; идентификатор сборки сохранён.

## Исправления

- `packages.config`: восстановлен обязательный граф Spire.XLS → HarfBuzzSharp 8.3.0.1 → NativeAssets. Всего 16 закреплённых пакетов; версии существующих пакетов не повышались.
- `Reinforcement.csproj`: возвращены ссылка на HarfBuzzSharp, штатный импорт Win32 native assets и импорт ValueTuple; проверяется наличие файлов NuGet. Исправлены OutputPath для Debug/Release x64. Сборка остаётся x64 и при выборе совместимой конфигурации Any CPU.
- `app.config`: перенаправление Unsafe соответствует поставленной версии 6.0.3.0; удалены перенаправления отсутствующих пакетов Microsoft.Extensions. Стандартный namespace записан без префикса; прежний префикс ns0 сам по себе ошибкой не был. DLL.config не заменяет конфигурацию хоста Revit.
- Восстановлена обязательная Authenticode-подпись после сборки. Событие PostBuildEvent вызывает Sign-Plugin.ps1 с SignTool, SHA256 и временной меткой DigiCert. Пароля в проекте нет.
- Удалён старый AfterClean, удалявший файлы установленного плагина Revit 2020 при очистке проекта.

Дополнительные изменения классов из задачи №2 сохранены отдельно в рабочей папке и в этот кандидат не включены. Код команд соответствует v1; изменена только версия файла DLL. Это позволяет проверять исправления конфигурации отдельно.

## Состав

`EC_BIM.sln`, `NuGet.Config`, `Программа/` — исходники и ресурсы. `Установка/ENSPlugin/` — подписанная DLL, её конфигурация и зависимости, включая подпапки native DLL. PFX и закрытый ключ в комплект не входят. `Проверки/` — протокол проверок и сравнение зависимостей. `SHA256.json` — контрольные суммы.

## Сборка и подпись

Распакуйте комплект в короткий путь, например C:\EC_BIM. Нужны Visual Studio 2022 / Build Tools с .NET desktop и Developer Pack .NET Framework 4.8, Revit 2024 и SignTool из Windows SDK.

До запуска Visual Studio или Build.ps1 задайте в окружении:

- `EC_BIM_SIGN_PFX_PATH` — полный путь к вашему PFX; по умолчанию сохранён прежний C:\Certs\MyRevitPlugin.pfx.
- `EC_BIM_SIGN_PFX_PASSWORD` — пароль PFX, вводимый локально; не сохраняйте его в проекте и переписке.
- `EC_BIM_SIGNTOOL_PATH` — полный путь к signtool.exe, если он не находится автоматически в Windows SDK.

Вместо PFX можно использовать `EC_BIM_SIGN_CERT_THUMBPRINT` для сертификата из личного хранилища текущего пользователя. Не задавайте его одновременно с выбором PFX. По умолчанию используется исходный сервер временных меток `http://timestamp.digicert.com`; другой RFC3161 сервер задаётся через `EC_BIM_SIGN_TIMESTAMP_URL`. Это штатный URL из документации Microsoft и DigiCert; закрытый ключ и пароль серверу не передаются.

Запустите `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Программа\Build.ps1` либо откройте решение, восстановите NuGet и соберите Release/x64. Для нестандартного расположения Revit задайте `-RevitInstallDir`. Сборка завершается ошибкой, если подпись не выполнена. `-AllowUnsignedBuild` / MSBuild `SignPlugin=false` предназначены только для явной локальной проверки компиляции; такой результат не является подписанным выпуском.

Готовая DLL v2 подписана предоставленным сертификатом (thumbprint 823DC59C4187E930F5B5D4E1710F3255E41FE259), временная метка DigiCert присутствует. Проверка доверия Windows сообщает о недоверенном корневом сертификате. Сертификаты в доверенные хранилища автоматически не устанавливались; на рабочих местах возможен запрос о неизвестном издателе.

## Установка и проверка в Revit

Закройте Revit, сохраните прежний манифест EC_BIM вне папок Addins/2024. Запустите `Установка/InstallCandidate.ps1`. Он создаёт отдельную папку кандидата и останавливается при конфликте с установленным EC_BIM. Копировать нужно весь ENSPlugin вместе с подпапками, а не одну Reinforcement.dll. Для отката при закрытом Revit уберите манифест кандидата и верните прежний. Установщик в ходе подготовки не запускался.

Автообновление по сети отключено через EnableAutomaticUpdates=false, чтобы оно не заменяло проверяемый кандидат. На копии модели проверьте загрузку плагина, использовавшиеся команды и операции Excel. Приёмочный сценарий ТЗ: выбрать три проёма, у двух заполнены Марка, Ширина и Высота, у третьего отсутствуют необходимые данные; ожидаются две марки и один понятный пропуск. Требуются подходящий вид и загруженное семейство марки.

## Проверки и ограничения

Пакеты кандидата восстановлены в пустую папку; исходники кандидата повторно собраны и подписаны. Release/x64 и Debug/x64 полностью пересобраны без ошибок по установленному API Revit 2024. Сохраняются предупреждения старых команд. В этой среде нет Visual Studio; использован переносимый MSBuild 17.8 и Roslyn 4.8 с эталонными сборками .NET Framework 4.8 и явными путями инструментария. Штатный Build.ps1 проверен с этими путями; запуск IDE Visual Studio не выполнялся.

В изолированной копии фактического комплекта выполнены JSON round-trip, чтение XLSX через ExcelDataReader, запись и чтение XLSX через Spire.XLS, вызов HarfBuzzSharp.Buffer с загрузкой x64/libHarfBuzzSharp.dll. На v1 три проверки проходят, четвёртая воспроизводимо падает из-за отсутствующего HarfBuzzSharp; на v2 проходят все четыре. Дополнительно эти четыре операции прошли с runtime из установленного Revit.exe.config и без assemblyBinding, в отдельных процессах .NET Framework. Это не воспроизводит уже загруженные сборки и другие плагины реального Revit. Подпись и временная метка проверены отдельно; доверие цепочке не подтверждено по причине выше.

Revit и реальные модели для приёмки не запускались. Кандидат имеет статус «На проверке»; принятого выпуска в 04 нет.
